# data — картинки и файлы бота UwU

Здесь лежат обложки сообщений бота, логотипы и установщики приложения.
Бот берёт картинки прямой ссылкой:

```
https://raw.githubusercontent.com/UwU-VPN-db/data/main/<путь к файлу>
```

Имена только латиницей и в нижнем регистре, без пробелов: кириллическое имя
в ссылке превращается в `%D0%BA%D0%BB%D1%8E%D1%87%D0%B8`, и в коде уже не видно,
что это за файл.

## screens/ — обложки экранов бота

Каждому экрану — своя картинка. Соседние экраны не должны повторяться: по одинаковой
обложке человек не замечает, что экран вообще сменился. Список сопоставлений живёт
в `ui.py` бота, блок «КАРТИНКИ ЭКРАНОВ».

| Файл | Где показывается | Константа в `ui.py` |
| --- | --- | --- |
| `welcome_1.jpg` … `welcome_6.jpg` | приветствие при `/start`, выбирается случайно | `pic_welcome` |
| `captcha.jpg` | проверка «я не робот» у нового пользователя | `pic_robot` |
| `main_menu.png` | главное меню | `pic_main_menu` |
| `keys_menu.jpg` | список ключей | `pic_keys_menu` |
| `key_menu.jpg` | меню одного ключа | `pic_key_menu` |
| `sub_menu.jpg` | продление подписки | `pic_sub_menu` |
| `bonus_menu.jpg` | бонусный счёт | `pic_bonus_menu` |
| `error.jpg` | любая ошибка ввода | `pic_custom_deposit_err` |
| `devices.jpg` | список устройств ключа | `pic_devices` |
| `device_new.jpg` | уведомление «Новое устройство» | `pic_device_new` |
| `key_rename.jpg` | ввод нового названия ключа | `pic_key_rename` |
| `ref_menu.jpg` | «Пригласить друга» | `pic_ref_menu` |
| `support.gif` | поддержка | `pic_support` |
| `promo_input.png` | ввод промокода | `pic_promo_input` |
| `pay_wait.gif` | чек выставлен, ждём оплату | `gif_yoocheck_check` |
| `pay_success.gif` | оплата прошла | `gif_yoocheck_success` |

Своей картинки пока нет у двух экранов — вместо неё бот показывает серую заглушку
с подписью: карточка устройства и уведомление о лимите устройств.
Чтобы заменить заглушку, положите файл в `screens/` и поправьте одну строку в `ui.py`.

Обложки лучше держать горизонтальными или квадратными. Вертикальную картинку телефон
обрезает до квадрата, а компьютер показывает целиком — экран выглядит по-разному на
разных устройствах. Поэтому `pay_wait.gif` приведён к квадрату: исходный клип
240×424 стоит по центру, по бокам размытый фон из него же.

## stock/ — запас под будущие экраны

Картинки без места: подходят на замену заглушкам, но пока никуда не назначены.
`cat_waiting.jpg`, `money_cigar.jpg`, `thanks_vip.jpg`, а также два запасных

## apps/ — установщики V2rayTun

`v2raytun_setup.exe` для Windows и `v2raytun.apk` для Android. Бот на них не ссылается,
ссылки раздаются вручную.

## Как добавить картинку

1. Положить файл в нужную папку, имя — латиницей, в нижнем регистре, через `_`.
2. Для обложки экрана — поправить ссылку в `ui.py` бота и перезапустить его.
3. Telegram кеширует превью по ссылке. Если заменить файл, оставив прежнее имя,
   у части пользователей какое-то время будет показываться старая картинка.
   Надёжнее загрузить файл под новым именем и поменять ссылку.
